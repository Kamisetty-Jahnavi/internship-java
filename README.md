# Java Internship Projects – VaultofCodes

## 📌 Overview
This repository contains the projects I developed during my one-month internship as a Java Programming Intern at VaultofCodes. These projects focus on core Java concepts, object-oriented programming, and basic GUI development.

---

## 🛠 Tech Stack
- Java  
- Core Java (OOP, Collections)  
- Swing (GUI Development)  

---

## 📂 Projects

### 🔹 Calculator GUI
A desktop-based calculator built using Java Swing.

**Features:**
- Basic arithmetic operations (+, -, *, /)
- Trigonometric functions (sin, cos, tan)
- Square root and exponent operations
- Displays calculation history

---

### 🔹 Password Strength Indicator
A GUI application that checks password strength in real-time.

**Features:**
- Strength levels: Weak, Medium, Strong
- Progress bar visualization
- Show/Hide password option
- Enables submit only for strong passwords

---

### 🔹 To-Do List Application
A console-based application to manage daily tasks.

**Features:**
- Add tasks
- Remove tasks
- Display task list
- Uses ArrayList for storage

---

## 🚀 How to Run

2. Open in any Java IDE (IntelliJ / Eclipse / VS Code)  
3. Compile and run any `.java` file
